# Roadmap

## 阶段一:地基(当前)

- [x] 仓库结构(README、LICENSE、CONTRIBUTING、install.sh)
- [x] 第一批 10 个核心技能
- [x] 风格指南与质量门禁
- [ ] GitHub 仓库发布(创建远程仓库、推代码、开 Discussion)
- [ ] 通过 `gh skill publish` 校验并启用不可变 Release
- [ ] 首个 Release(v0.1.0)打 tag

## 阶段二:冷启动(0 → 500 星)

- [ ] 英文 README 校对,SEO 关键词(agent skills、Chinese、Claude Code、Codex)
- [ ] 在 Linux.do、V2EX、Reddit(r/ClaudeAI 等)、X 发布介绍帖
- [ ] 投稿:阮一峰周刊、HelloGitHub、GitHubDaily
- [ ] 向现有 awesome-* 技能清单提 PR,互相导流
- [ ] 收集 issue,每周迭代 1-2 个技能

## 阶段三:扩展(500 → 5000 星)

- [ ] 新增垂直技能包(如:中文测试技能、游戏开发技能、论文写作技能)
- [ ] 提供配套示例项目(用本仓库技能完成一个小项目的真实案例)
- [ ] 支持更多工具(Gemini CLI、Windsurf、GitHub Copilot)
- [ ] 建立贡献者社区,开放"技能提案"模板

## 阶段四:生态(5000 星+)

- [ ] 官方 CLI 化的安装体验(或接入 npx 分发)
- [ ] 技能评测体系(每个技能附带评测集)
- [ ] 与更多中文开发者社区建立合作

## 质量原则

- 每个技能必须:原创、可触发、可执行、可验证;
- 宁缺毋滥:质量不合格的技能不收录;
- 中文优先:description 中英双语,内容以中文为主。
