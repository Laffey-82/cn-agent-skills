## 接下来

### 技能扩充

- 中文团队高频场景:数据库迁移评审、环境排障、安全加固、性能剖析
- 垂直领域:游戏开发、论文写作、测试专项
- 每个新技能:先调研同类做法 → 评审定位 → 原创实现 → 官方校验 → 实测触发 → 才能合并

### 质量

- 全仓库文案保持自然中文,禁止 AI 腔(排比、空泛形容词、emoji 堆砌)
- 技能必须实测,不能只写文档不验证

### 分发

- 接入 gh skill 搜索,保证所有技能可被一条命令安装
- 英文 README 与技能 description 持续校对

## 原则

- 原创,不搬运
- 每个技能解决一个具体问题,不做万能技能
- 质量不合格的不收录
