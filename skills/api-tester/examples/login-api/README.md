# API 契约测试示例:登录接口

对应 `api-tester` 技能的完整演示:从真实代码确认契约 → 列出用例 → 确认环境 → 执行 → 出报告。

## 契约(从 app.py 确认)

`POST /api/login`,入参 `{username, password}`:

- 成功:200 + `{code: 0, token: ...}`;
- 参数缺失:400;
- 账号或密码错误:401。

## 运行

```bash
pip install -r requirements.txt
python test_api.py
```

脚本会自动启动示例服务、跑 5 个用例(正常/密码错/账号不存在/缺参/空 body)、结束服务。

## 预期输出

```text
[PASS] 正常登录: 期望 200,实际 200 (返回 token)
[PASS] 密码错误: 期望 401,实际 401 (账号或密码错误)
...
共 5 个用例,失败 0 个
```

## 契约和代码不一致时

把 `app.py` 里 401 改成 403,重跑,`密码错误` 和 `账号不存在` 两个用例会 FAIL——这就是"契约测试发现接口实现漂移"的演示。
