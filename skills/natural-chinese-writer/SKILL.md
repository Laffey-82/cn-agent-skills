# 自然中文写作

## 何时使用

- 用户说"这段文字看着别扭,改一下""写得像人一点";
- 要发布 README、博客、公众号文章,想去掉明显的机器痕迹;
- 文案里全是排比、感叹号和"赋能""闭环"这类词;
- 内容是对的,但读起来像翻译腔。

## 使用步骤

### 第 1 步:找出问题写法

通读原文,标记以下特征:

| 特征 | 例子 |
|---|---|
| 排比三连 | "不仅…而且…更是…" |
| 空泛形容词 | "强大""极致""无缝""一站式" |
| 套话开头 | "众所周知""在当今时代""随着…的发展" |
| 感叹与口号 | "让我们一起!""相信我,你一定会爱上!" |
| emoji 堆砌 | 一句话一个 🚀✨🔥 |
| 翻译腔 | "这不仅仅是一个…更是一个…" |
| 过度礼貌 | "非常荣幸地""诚挚地邀请您" |

### 第 2 步:确认原意

改之前先想清楚原文到底要说什么,说不清的标出来问用户,不要硬编。

### 第 3 步:改写

改写规则:

1. **用具体代替空泛**:把"功能强大"改成具体能做什么;
2. **句子长短错落**:长句拆短,偶尔来一句短的;
3. **从事实讲起**:先说什么情况、什么问题,再说怎么解决;
4. **去掉客套**:能删的"我们相信""非常荣幸"直接删;
5. **保留作者的判断和语气**:如果原文有明显态度,不要改成四平八稳;
6. **删 emoji 和装饰性符号**:只保留必要的目录标记;
7. **避免整齐划一**:不要每段都是"首先…其次…最后…"。

### 第 4 步:输出

输出三部分:

1. 改写后的全文;
2. 主要改动说明(改了哪些地方、为什么);
3. 仍存疑的地方(需要作者确认的事实或态度)。

## 输入与输出

- 输入:一段中文文案(README、文章、公告等);
- 输出:改写稿 + 改动说明 + 待确认项。

## 示例

**原文:**

> 在这个日新月异的数字时代,我们的产品应运而生。它不仅功能强大、性能卓越,更拥有无与伦比的用户体验,是您的不二之选!🚀

**改写后:**

> 写代码写累了?这个工具能帮你把重复的活自动化,支持 40 多种常用场景。装上就能用,不需要配环境。

**改动说明:**

- 删掉"日新月异的数字时代"这类套话,直接说使用场景;
- "功能强大、性能卓越"换成具体的能力描述;
- 去掉感叹号和 emoji,语气放平。

## 注意事项

- 不改变事实:具体数字、功能清单不能为了顺口删掉;
- 不替作者表态:作者原本的态度保留,只改表达;
- 面对"既要文采又要干货"的要求,先保干货;
- 改完自己读一遍,读着像人写的才算完。

## 不适用场景

- 用户要的是广告文案创意(那是创作,不是改写);
- 技术文档需要精确术语,不适合口语化;
- 原文事实不清,用户又不在场确认。

## 验证方式

1. 触发:"这段文字看着别扭,改一下";
2. 检查:改写稿不出现表格里的特征写法;
3. 复核:把改写稿和原文并排读,确认事实无遗漏、原意无偏差。
