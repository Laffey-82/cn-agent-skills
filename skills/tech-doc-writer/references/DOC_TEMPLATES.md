# 文档结构模板

## README

```markdown
# 项目名

> 一句话定位:给谁用、解决什么问题。

## 功能特性
- 每个特性一句话,说"能做什么",不说"支持 X"这种空话

## 快速开始
1. 安装依赖
2. 配置环境变量
3. 启动
4. 验证(能看到什么)

## 使用示例
- 最常见的 2-3 个用法,代码可复制可运行

## 配置说明
- 环境变量表:名称 | 必填 | 默认值 | 说明

## 常见问题
- 按"现象 → 原因 → 解决"写

## 目录结构
- 只列重要目录,一行一个说明

## License
```

## 快速开始怎么写

```markdown
要求:Node.js 18+

1. 安装依赖:
   npm install
2. 配置环境变量:
   cp .env.example .env
3. 启动开发服务:
   npm run dev
4. 打开 http://localhost:3000,能看到首页
```

要求:

- 每步都有命令,命令能跑通;
- 有验证步骤(打开什么、看到什么);
- 常见坑写进 FAQ,不打断主流程。

## API 文档

```markdown
## 接口名
- 方法:GET /api/users/:id
- 认证:Bearer Token
- 参数:
  | 名称 | 类型 | 必填 | 说明 |
- 响应:
  ```json
  {"code": 0, "data": {...}}
  ```
- 错误码:
  | 错误码 | 含义 |
```

## 架构文档

```markdown
## 模块划分
## 数据流
## 关键设计决策(为什么这么做)
## 部署
```

## 文档质量自查

- [ ] 每个命令本地跑通过;
- [ ] 示例代码可复制可运行;
- [ ] 配置表和代码里的实际配置一致;
- [ ] 有验证步骤(做完能看到什么);
- [ ] 常见坑有记录;
- [ ] 变更代码后文档同步更新。
